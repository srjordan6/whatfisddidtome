# whatfisddidtome.com

Static site. Files live in `public/`. Deployed by Cloudflare Workers Builds from the `main` branch with `npx wrangler deploy`.

Pre-launch safeguards (remove when ready to launch):
- `public/robots.txt` disallows all crawlers
- `<meta name="robots" content="noindex">` in each HTML page

Editing rule: every factual statement must trace to a dated document. Refer to District staff by title. Never name or picture the author's son or any other child.
